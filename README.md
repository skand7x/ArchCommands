# Arch Linux Command Reference

This repository is a comprehensive collection of **Arch Linux commands** for system management, package handling, networking, disk operations, and more. Whether you're a beginner or a seasoned Arch user, this resource provides quick access to all essential commands.

## 📂 Contents

- ✅ System Information and Control
- 👥 User and Group Management
- 📦 Package Management with `pacman` and `yay`
- 💾 Filesystem and Disk Utilities
- 📡 Networking and Wi-Fi Setup
- 🧹 Cache Cleaning and Orphan Removal
- 📋 Backup and Restore of Packages
- 🛠️ Useful Troubleshooting Commands

## 📶 Wi-Fi Setup Without Ethernet

Includes full instructions on how to connect to a Wi-Fi network during a fresh Arch install using the `iwctl` tool — perfect for laptops and other systems without a wired connection.

## 📄 File Structure

- `arch_linux_commands.md` — Main cheat sheet with categorized command tables

## 🚀 Usage

This repo is designed to be:
- A **cheat sheet** for experienced users
- A **learning tool** for newcomers
- A **reference guide** during Arch installations or system setup
